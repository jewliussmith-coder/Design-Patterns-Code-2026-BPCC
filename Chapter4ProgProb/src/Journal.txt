The Factory Method pattern uses inheritance to let each spawner decide which enemies it creates. If we add a new level such as a MountainSpawner, we can create a new class that extends EnemySpawner and override createEnemy() to create mountain enemies. The existing ForestSpawner and DungeonSpawner do not need to be changed. This makes the game easier to expand because each level can have its own enemy creation rules.
